# PZK ZLRC Compat — A-Life (+Jeem) x ZomboRut / ZomboLust x Being Female (B42.21)  v 1.0

Separate compatibility mod. **No code from any of the three mods is copied** (ZomboRut's license forbids derivatives);
everything hooks through global tables / events at runtime. Enable it after all of them (`loadModAfter` is set).
Sandbox page: **ZLRC**. Turn on `Debug logging` and look for `[ZLRC]` lines in the console when reporting problems.

## Whats adding and Limits
* Ask for X with friendly NPCS
* Ability to wash (desinfect) zombie corpse to not get stench
* Bik animations from Zombolust/Zombodesire
* Being Female integration
* A-life NPC will not chasing over dragged & subdued body
* Some sandbox options

Woks in SP. MP not tested (I don't have possibility to do that), Male player not tested. Some additional features, polishing will come later.
